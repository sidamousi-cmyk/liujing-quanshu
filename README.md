# 六经全书｜六经辨证与中西医综合临床知识平台

**杏林砚斋·白书田·宇宙中医研究所·编纂**

> 以中医之深邃，融现代医学之精密。以六经辨证为纲，以临床实践为本，探索传统医学知识的数字化整理与中西医协同应用。

## 一、项目简介

《六经全书》是以《伤寒论》《金匮要略》为经典基础、以六经辨证为主线构建的数字中医知识平台与临床辅助诊疗系统。项目采用“六经定位—证候分析—方剂参考—针灸调节—现代医学指标”相互参照的组织方式，为中医理论学习、医学文献查阅、临床资料整理和辅助决策提供结构化工具。

平台遵循“气机为本、六经为纲”的研究思路，将太阳、少阳、阳明、太阴、少阴、厥阴六经辨证与具体病种、证候、经方及现代医学检查信息建立关联，并保留医师的独立辨证与处方判断。

## 四、主要特色

### 六经辨证知识体系
按照“太阳开—少阳枢—阳明合—太阴承—少阴根—厥阴转”的研究脉络，整理六经证候、典型表现、方证对应及跨经关联。

### 中药方剂与临床处方辅助
汇集经典方剂及专病参考方案。围绕病名、主证、兼证等信息提供候选方剂，支持药味、剂量与备注的结构化编辑。候选方不等于自动确定的临床处方，最终应由具备相应资质的专业人员审查。

### 三类针灸资料
设置十四经常用穴、董氏奇穴、平衡针灸等模块，整理穴位名称、定位、操作注意事项和配穴资料。针灸操作应由受过专业培训的人员实施。

### 中药山海经
按植物、矿物、动物等类别组织药材资料，提供药名、性味归经、传统应用、来源和安全参考信息，便于从方剂中的单味药进一步查阅。

### 中西医信息参照
在辨证资料之外，关联必要的危险信号、推荐检查、现代医学诊断依据、常规治疗信息、随访指标及转诊条件，方便临床资料核查与跨学科沟通。

### 多终端与离线应用
项目规划并持续开发网站在线版、Windows 桌面版、共享版、浏览器版及手机端应用；离线数据包、版本更新和设备授权功能以对应发布版本的实际支持情况为准。

## 五、标准化诊疗卡

平台按统一字段建设标准化诊疗卡，包括：

**病名 → 触发词 → 必问项 → 危险信号 → 建议检查 → 六经定位 → 证候分支 → 中药首选/备选 → 针灸 → 董氏奇穴 → 平衡针灸 → 西药候选 → 随访指标 → 转诊条件**

其目标是让经典理论、临床辨证资料与现代检查要点能够在同一工作流程中检索和比对。

## 六、使用定位与安全说明

《六经全书》是医学知识整理与辅助诊疗研究项目，不取代专业医疗诊断、必要的检验检查、急症救治及规范治疗。方药剂量、禁忌、药物相互作用和特殊人群风险需要逐例审核；肿瘤、心脑血管急症等疾病的规范治疗不应因使用本平台而延误。

部分临床数据库、病例和授权模块不对公众开放。临床病例应依法依规去标识化处理，个人健康数据不得直接公开上传到开源仓库。
